# 🛍️ ShopSmart AI

AI-Powered E-Commerce Product Recommendation System.

## 🌐 Live Demo

https://ecommerce-ai-recommendation.onrender.com

## 🚀 Features

- AI Product Recommendations
- Product Search
- Category Filter
- Price Sorting
- Shopping Cart
- Wishlist
- Product Rating
- Checkout
- Order History
- User Profile

## 🛠️ Technologies

- HTML
- CSS
- JavaScript
- Python
- Flask
- Pandas
- Scikit-learn
- TF-IDF
- Cosine Similarity

## 🤖 AI Method

The system uses Content-Based Filtering with TF-IDF and Cosine Similarity to recommend similar products.
